# Lance Fermo — Portfolio

A professional portfolio website designed using Swiss / International Typographic Style principles.

## Local Development (XAMPP)

1. Ensure this project is located at: `C:\xampp\htdocs\lance-portfolio\`
2. Start the **Apache** module in the XAMPP Control Panel. MySQL is not required as this is a static website.
3. Open your browser and visit: [http://localhost/lance-portfolio/](http://localhost/lance-portfolio/)

## Technologies Used

* Vanilla HTML5
* CSS3 (CSS Variables, Grid, Flexbox)
* Vanilla JavaScript

## Git & GitHub Workflow

This project is connected to the remote repository: `https://github.com/codexversailles/portfolio`

To push updates:

```bash
# View changes
git status

# Stage changes
git add .

# Commit changes
git commit -m "Update portfolio"

# Push to GitHub (ensure you are on the correct branch, typically 'main')
git push origin main
```

## Design Language

* **Grid:** 12-column (desktop), 6-column (tablet), 4-column (mobile).
* **Typography:** Clean sans-serif, strong hierarchy, large display type.
* **Colors:** Black, White, Red accent, Gray metadata.
* **Layout:** Asymmetrical, editorial, generous whitespace.
